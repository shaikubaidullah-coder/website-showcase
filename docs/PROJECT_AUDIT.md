## 2. Integrity and Honest Representation Rules

1. **No Fictitious Testimonials:** Never create fake client quotes. Use real quotes where available or omit them entirely.
2. **No Inflated Metrics:** Do not write "10x speedup" or "50,000 users" unless backed by analytics.
3. **Verified Technologies Only:** Every badge on a card must reflect dependencies actually discovered in `package.json` or source HTML.
4. **Live Verification Status:** Each card explicitly labels the deployment host (Netlify / Vercel) and HTTP status.
